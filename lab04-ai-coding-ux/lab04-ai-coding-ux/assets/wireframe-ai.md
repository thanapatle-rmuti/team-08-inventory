# Text Wireframe (ASCII Layout) - Lab 04

> **ระบบคลังสินค้าเครื่องเขียนและดิจิทัล (Inventory System)**  
> **กลุ่มผู้ใช้เป้าหมาย:** สมศรี (พนักงานคลังสินค้าอาวุโส ทักษะเทคโนโลยี 2/5 ใช้งานผ่านแท็บเล็ตและหน้าจอตั้งโต๊ะ)

## 1. หน้าจอที่ 1: เข้าสู่ระบบ (Login Screen)

```text
+-----------------------------------------------------------------------+
|  ระบบสต็อกร้านเขียนดี (Inventory Management System)                     |
+-----------------------------------------------------------------------+
|                                                                       |
|                     [ โลโก้ร้านเขียนดี ]                                |
|                                                                       |
|  +-----------------------------------------------------------------+  |
|  |  เข้าสู่ระบบผู้ใช้งาน (Sign In)                                    |
|  |                                                                 |
|  |  ชื่อผู้ใช้ (Username) *                                          |
|  |  [ somsri.j                                                   ]  |
|  |                                                                 |
|  |  รหัสผ่าน (Password) *                                            |
|  |  [ **********                                                 ]  |
|  |                                                                 |
|  |  [!] ข้อผิดพลาด (Validation Error State):                          |
|  |  (X) ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบแป้นพิมพ์อีกครั้ง    |
|  |                                                                 |
|  |  +-----------------------------------------------------------+  |
|  |  | [ปุ่มหลัก: เข้าสู่ระบบ (Sign In) - Primary Color #1E40AF]     |  |
|  |  +-----------------------------------------------------------+  |
|  |                                                                 |
|  |  [?] ลืมรหัสผ่าน? ติดต่อผู้ดูแลระบบโทร 02-123-4567               |
|  +-----------------------------------------------------------------+  |
|                                                                       |
+-----------------------------------------------------------------------+
```

### คำอธิบาย Usability & Accessibility ของหน้า Login:
- **Visible Label:** มีป้ายกำกับ `ชื่อผู้ใช้ (Username) *` เหนือกล่องข้อความอย่างชัดเจน ไม่ใช้ Placeholder แทน Label
- **High Contrast:** ปุ่มหลักใช้สีน้ำเงินเข้ม `#1E40AF` ตัวอักษรสีขาว อ่านง่าย ชัดเจน
- **Actionable Error:** เมื่อล็อกอินไม่ผ่าน มีไอคอน `(X)` และข้อความแนะนำให้ตรวจภาษาแป้นพิมพ์

## 2. หน้าจอที่ 2: หน้าแดชบอร์ดสรุปรายการสินค้า (Dashboard / Inventory List)

```text
+-----------------------------------------------------------------------------------+
| [ร้านเขียนดี]  | หน้าหลัก (Active) | + เพิ่มสินค้าใหม่ | รายงานยอดสต็อก | คุณสมศรี [ออกจากระบบ] |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  แดชบอร์ดสรุปรายการสินค้า (Inventory Dashboard)                                     |
|  -------------------------------------------------------------------------------  |
|  ค้นหาสินค้า: [ สมุด                          ] [ หมวด: ทั้งหมด v ] [ ค้นหา ]       |
|                                                                                   |
|  [ สรุปภาพรวม: สินค้าทั้งหมด 128 รายการ | สต็อกต่ำ 3 รายการ (!) | สินค้าดิจิทัล 15 รายการ ]|
|                                                                                   |
|  +-----------------------------------------------------------------------------+  |
|  | รหัส     | ชื่อสินค้า        | ชนิดสินค้า  | คงเหลือ | ราคา/หน่วย | สถานะ         |  |
|  +---------+------------------+------------+---------+------------+--------------+  |
|  | P-001   | สมุดกริด A5 ปกแข็ง | Physical   | 45 เล่ม | 85.00 บ.   | [ ปกติ ]     |  |
|  | P-002   | ปากกาเจล ดำ 0.5  | Physical   | 3 ด้าม  | 25.00 บ.   | [! ใกล้หมด]  |  |
|  | D-101   | E-Book จดสรุปสอบ | Digital    | ไม่จำกัด| 150.00 บ.  | [ พร้อมขาย ] |  |
|  | D-102   | License Key แผนงาน| Digital    | 12 keys | 490.00 บ.  | [ ปกติ ]     |  |
|  +-----------------------------------------------------------------------------+  |
|                                                                                   |
|  [ หน้าก่อนหน้า ]  หน้า 1 จาก 12  [ หน้าถัดไป ]                                   |
|                                                                                   |
|  +-----------------------------------------------------------------------------+  |
|  | [+ เพิ่มสินค้าใหม่ (Primary Button)]     [ พิมพ์รายงานสรุป (Secondary Button)] |  |
|  +-----------------------------------------------------------------------------+  |
+-----------------------------------------------------------------------------------+
```

### คำอธิบาย Usability & Accessibility ของหน้า Dashboard:
- **Type Differentiation:** แสดงคอลัมน์ `ชนิดสินค้า (Physical/Digital)` อย่างชัดเจน ช่วยให้พนักงานไม่สับสน
- **Accessible Status:** สถานะสินค้าใกล้หมดใช้ทั้งสีส้ม Warning (`#B45309`) และสัญลักษณ์ `[! ใกล้หมด]` เพื่อให้ผู้ที่มีภาวะตาบอดสีแยกแยะได้
- **Prominent Primary Action:** ปุ่ม `+ เพิ่มสินค้าใหม่` อยู่ในตำแหน่งเด่นทางซ้ายล่างและแถบเมนูด้านบน

## 3. หน้าจอที่ 3: เพิ่มสินค้าใหม่เข้าคลัง (Add Product Screen)

```text
+-----------------------------------------------------------------------------------+
| [ร้านเขียนดี]  | หน้าหลัก | + เพิ่มสินค้าใหม่ (Active) | รายงานยอดสต็อก | คุณสมศรี [ออก]  |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  [ แถบแจ้งเตือนความสำเร็จ (Success Banner State) ]                                  |
|  (✓) บันทึกสินค้า "สมุดสเก็ตช์ A4" (รหัส P-003) เข้าระบบเรียบร้อยแล้ว                |
|                                                                                   |
|  เพิ่มสินค้าใหม่เข้าระบบ (Add New Product)                                         |
|  กรุณากรอกข้อมูลสินค้าให้ครบถ้วน ช่องที่มีเครื่องหมาย (*) เป็นช่องที่จำเป็นต้องกรอก   |
|  -------------------------------------------------------------------------------  |
|                                                                                   |
|  1. ชนิดสินค้า (Product Type) *                                                   |
|     (•) สินค้าที่จับต้องได้ (Physical)       ( ) สินค้าดิจิทัล/ไฟล์ (Digital)       |
|                                                                                   |
|  2. รหัสสินค้า (Product SKU/Code) *                                               |
|     [ P-003                                                           ]           |
|                                                                                   |
|  3. ชื่อสินค้า (Product Name) *                                                   |
|     [ สมุดสเก็ตช์ A4 ปกคราฟต์                                           ]           |
|                                                                                   |
|  4. จำนวนสต็อกเริ่มต้น (Initial Quantity) *                                        |
|     [ -5                                                              ]           |
|     [!] ข้อผิดพลาด (Validation Error State):                                      |
|     (X) จำนวนสต็อกต้องเป็นตัวเลข 0 หรือมากกว่า (ไม่สามารถติดลบได้)                  |
|                                                                                   |
|  5. จุดแจ้งเตือนสต็อกต่ำ (Low Stock Threshold)                                    |
|     [ 10                                                              ]           |
|     (คำแนะนำ: ระบบจะแจ้งเตือนเมื่อสต็อกเหลือน้อยกว่าค่านี้)                         |
|                                                                                   |
|  6. ราคาต่อหน่วย (Unit Price ในสกุลเงินบาท) *                                      |
|     [ 120.00                                                          ]           |
|                                                                                   |
|  [ สำหรับสินค้าดิจิทัล ฟิลด์จะสลับเป็น: URL ดาวน์โหลด / License Key อัตโนมัติ ]    |
|                                                                                   |
|  -------------------------------------------------------------------------------  |
|  ปุ่มดำเนินการ:                                                                    |
|  +-----------------------------------+     +----------------------------------+   |
|  | [ปุ่มหลัก: บันทึกสินค้า (#1E40AF)]  |     | [ปุ่มรอง: ยกเลิก/กลับ (#E5E7EB)] |   |
|  +-----------------------------------+     +----------------------------------+   |
|                                                                                   |
+-----------------------------------------------------------------------------------+
```

### คำอธิบาย Usability & Accessibility ของหน้า Add Product:
- **Type Toggle:** Radio Button ให้เลือกชนิดสินค้า Physical หรือ Digital ชัดเจน ป้องกันการใส่ข้อมูลผิดบริบท
- **Inline Error with Solution:** Error แสดงใต้ช่องทันทีด้วยข้อความภาษาไทยที่ระบุวิธีแก้: `(X) จำนวนสต็อกต้องเป็นตัวเลข 0 หรือมากกว่า (ไม่สามารถติดลบได้)`
- **Success Feedback:** แสดงกล่อง Banner สีเขียว Success (`#15803D`) พร้อมเครื่องหมายถูก `(✓)` ยืนยันรหัสสินค้าที่เพิ่งบันทึก แก้ปัญหาความกังวลของพี่ศรี
